## ✧ &nbsp;things i've made &nbsp;✧

<details open>
<summary><b>🚚 &nbsp;HAULR — AI-Powered HOS Trip Planner & ELD Log Generator</b> &nbsp;·&nbsp; <i>2026, personal project</i></summary>

<br/>

A full-stack trip planner for U.S. truckers, built with **React, TypeScript, and Django REST Framework**.

- Plans routes against **four federal Hours-of-Service limits**, with a deterministic compliance engine written as a pure Python module — independent of Django request handling
- Auto-generates **FMCSA daily log sheets as SVG replicas** of the paper grid, exportable to PDF
- An **AI copilot** (Gemini 2.5 Flash + LangChain + LangGraph) that answers compliance questions with **RAG citations**

</details>

<details>
<summary><b>🎀 &nbsp;Aileen — AI-Powered Outbound Calling System</b> &nbsp;·&nbsp; <i>2026, work project</i></summary>

<br/>

An AI voice-calling platform that actually dials out. Built with **FastAPI, OpenAI Realtime API, Twilio, React, and Supabase**.

- Automated call scheduling, queue management, and retry logic for outbound campaigns
- Persona-based AI conversations with real-time audio streaming
- A React dashboard for client management, live call monitoring, and scheduling

</details>

<details>
<summary><b>🌙 &nbsp;DanaOne Line — Solar-Powered LoRa Emergency Network</b> &nbsp;·&nbsp; <i>2026, capstone</i></summary>

<br/>

An **offline** communication network for disaster-prone communities in Danao City, Cebu — no internet, no cell towers, no grid power required.

- Solar-powered **ESP32 + LoRa** mesh nodes with multi-hop routing and Wi-Fi access points
- Offline messaging, community updates, and offline maps over WebSockets
- Browser-based interface for real-time coordination during disasters

</details>

<details>
<summary><b>📖 &nbsp;AIdapted — AI Adaptable Education Platform</b> &nbsp;·&nbsp; <i>2025</i></summary>

<br/>

An AI tutoring platform for learners from elementary to college.

- Responsive frontend in HTML5 / CSS3 / JavaScript with a **Django + SQL** backend
- Adaptive assessments, topic customization, and progressive lessons
- Integrates multiple AI models (Gemini 2.0 Flash, GPT-4.1, Llama 4, DeepSeek R1, Phi-4) for personalized content

</details>

<details>
<summary><b>🐣 &nbsp;ChikaDing — Automated Chicken Feeding System</b> &nbsp;·&nbsp; <i>2025</i></summary>

<br/>

An **Arduino + ESP32** feeder with ultrasonic sensors and an RTC module for precision feeding.

- Web connectivity for real-time alerts, remote monitoring, and custom feeding schedules
- Durable metal prototype built to cut feed waste and improve poultry care

</details>
